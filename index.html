ดูเฉลยข้อ 1

ทุกตารางในเฉลยคิดจากตาราง owner / land ชุดเดียวกับในโจทย์ (↑ กลับไปดูตาราง) · แต่ละข้อคิดจากข้อมูลตั้งต้น ไม่ได้ต่อจากผลของข้ออื่น · คอลัมน์ มาจาก land_id บอกว่าแถวนั้นมาจากแถวไหนในตารางโจทย์

วิธีคิดทุกข้อ: อยากได้อะไร (SELECT) → จากตารางไหน (FROM / JOIN) → เงื่อนไขอะไร (WHERE) → จัดกลุ่ม/เรียงไหม (GROUP BY / HAVING / ORDER BY)

1.5 ข้อมูลอยู่คนละตาราง → JOIN

1.6 นับแยกกลุ่ม + กรองหลังนับ → GROUP BY + HAVING

1.7 รวมยอดของแต่ละคน → JOIN + SUM + GROUP BY
SELECT o.name, SUM(l.price) AS total_price
FROM owner o
JOIN land l ON o.owner_id = l.owner_id
GROUP BY o.owner_id, o.name;
"แต่ละคน" = GROUP BY · group ด้วย owner_id ด้วยกันกรณีชื่อซ้ำ · คอลัมน์ที่อยู่ใน SELECT แต่ไม่ได้อยู่ในฟังก์ชัน (name) ต้องอยู่ใน GROUP BY
ผลลัพธ์: มาลี = 2,500,000 + 900,000 · วิชัย = 3,600,000 + 600,000 · สุดาไม่โผล่เพราะไม่มีที่ดิน (ถ้าอยากให้โผล่เป็น NULL ใช้ FROM owner o LEFT JOIN land l)

จุดที่มักโดนหักคะแนน

  • กรองหลังจัดกลุ่มต้องใช้ HAVING ไม่ใช่ WHERE
  • UPDATE / DELETE ต้องมี WHERE เสมอ

ข้อ 3 · เขียนโปรแกรม (35 คะแนน)

เขียนโปรแกรม ระบบจองคิวรับบริการสำนักงานที่ดิน ด้วยภาษาใดก็ได้ ให้มี 5 ส่วน:
  1. Login ของเจ้าหน้าที่ ถ้าใส่ผิด 3 ครั้งให้ล็อก
  2. จองคิว รับเลขบัตรประชาชน ประเภทบริการ (จดทะเบียนสิทธิ / รังวัด / ขอคัดสำเนา) และวันที่ โดยเลขบัตรต้องเป็นตัวเลข 13 หลัก และคนเดียวกันห้ามจองซ้ำในวันเดียวกัน
  3. ค้นหาคิว จากเลขบัตรประชาชน
  4. ยกเลิกคิว จากหมายเลขคิว โดยต้องถามยืนยันก่อน
  5. รายงาน จำนวนคิวของแต่ละประเภทบริการในวันที่ระบุ
ดูเฉลยข้อ 3 (3 แบบ: โค้ด / Flowchart / ภาษาไทย)

คิดก่อนเขียน: โจทย์แบบ "ระบบ 5 process" เกือบทุกข้อคือโครงเดียวกัน = Login → เมนูวนซ้ำ → เพิ่ม / ค้นหา / ยกเลิก / รายงาน จำโครงนี้ไว้แล้วเปลี่ยนแค่ชื่อข้อมูล

ส่วนทำอะไรต้องเช็ค (validation)ถ้าเป็น SQL
1Loginวนรับ user/pass สูงสุด 3 รอบผิดครบ 3 ครั้ง → ล็อกSELECT
2จองคิวรับข้อมูล → เก็บลงรายการบัตร 13 หลัก, เลือกบริการถูก, ไม่จองซ้ำวันเดียวกันINSERT
3ค้นหาหาคิวทั้งหมดของเลขบัตรนั้นไม่เจอ → แจ้งSELECT … WHERE
4ยกเลิกเปลี่ยนสถานะเป็น "ยกเลิก"เป็นตัวเลข, มีคิวนี้จริง, ถามยืนยันUPDATE
5รายงานนับคิวแต่ละบริการในวันนั้นนับเฉพาะสถานะ "จอง"COUNT + GROUP BY

ข้อมูลแต่ละคิวเก็บเป็น dictionary เช่น {"no": 1, "id_card": "...", "service": "รังวัด", "date": "2026-11-21", "status": "จอง"} แล้วรวมไว้ใน list ชื่อ queues (เหมือนตาราง 1 ตาราง แต่ละ dict = 1 แถว)

ถ้าโจทย์ให้เลือกวิธีเขียน เลือกอะไรดี
  • ภาษาไทยแบบเป็นขั้นตอน → แนะนำ ถ้ายังไม่คล่องโค้ด เขียนเร็วสุด ไม่มีเรื่อง syntax ผิด แต่ต้องครบ ลำดับ + เงื่อนไข + วนซ้ำ + validation เหมือนโค้ด ไม่ใช่เขียนบรรยายลอยๆ
  • โค้ด → คะแนนเต็มได้ง่ายสุดถ้าเขียนถูก แต่ถ้า syntax ผิดเยอะหรือค้างกลางทาง เสียทั้งข้อ
  • Flowchart → ใช้เวลาวาดนานสุดสำหรับระบบ 5 ส่วน · ถ้าจำเป็นต้องวาด ให้วาดโปรแกรมหลัก 1 รูป ใช้สัญลักษณ์ Predefined Process (สี่เหลี่ยมมีขีดข้าง) แทนแต่ละส่วน แล้ววาดละเอียดแค่ส่วนที่ซับซ้อนสุด (จองคิว)
users = {"admin": "1234"}
SERVICES = ["จดทะเบียนสิทธิ", "รังวัด", "ขอคัดสำเนา"]
queues = []      # แต่ละคิว = {no, id_card, service, date, status}
next_no = 1

# 1. Login
def login():
    for i in range(3):
        u = input("Username: ")
        p = input("Password: ")
        if users.get(u) == p:
            print("เข้าสู่ระบบสำเร็จ")
            return True
        print("ไม่ถูกต้อง เหลือ", 2 - i, "ครั้ง")
    print("ล็อกบัญชี")
    return False

def valid_id(id_card):
    return len(id_card) == 13 and id_card.isdigit()

# 2. จองคิว
def book():
    global next_no
    id_card = input("เลขบัตรประชาชน: ")
    if not valid_id(id_card):
        print("เลขบัตรต้องเป็นตัวเลข 13 หลัก"); return
    for i, s in enumerate(SERVICES, 1):
        print(i, s)
    c = input("เลือกบริการ: ")
    if c not in ("1", "2", "3"):
        print("ไม่มีบริการนี้"); return
    date = input("วันที่ (YYYY-MM-DD): ")
    for q in queues:   # ห้ามจองซ้ำวันเดียวกัน
        if q["id_card"] == id_card and q["date"] == date and q["status"] == "จอง":
            print("วันนี้มีคิวอยู่แล้ว"); return
    queues.append({"no": next_no, "id_card": id_card,
                   "service": SERVICES[int(c) - 1],
                   "date": date, "status": "จอง"})
    print("จองสำเร็จ หมายเลขคิว", next_no)
    next_no += 1

# 3. ค้นหาคิว
def search():
    id_card = input("เลขบัตรประชาชน: ")
    found = [q for q in queues if q["id_card"] == id_card]
    if not found:
        print("ไม่พบข้อมูล"); return
    for q in found:
        print(q["no"], q["service"], q["date"], q["status"])

# 4. ยกเลิกคิว
def cancel():
    no = input("หมายเลขคิว: ")
    if not no.isdigit():
        print("ต้องเป็นตัวเลข"); return
    for q in queues:
        if q["no"] == int(no) and q["status"] == "จอง":
            if input("ยืนยันยกเลิก (y/n): ") == "y":
                q["status"] = "ยกเลิก"
                print("ยกเลิกแล้ว")
            return
    print("ไม่พบคิวนี้")

# 5. รายงาน
def report():
    date = input("วันที่: ")
    for s in SERVICES:
        n = sum(1 for q in queues
                if q["date"] == date and q["service"] == s and q["status"] == "จอง")
        print(s, ":", n, "คิว")

# เมนูหลัก
def main():
    if not login():
        return
    menu = {"1": book, "2": search, "3": cancel, "4": report}
    while True:
        print("1.จองคิว 2.ค้นหา 3.ยกเลิก 4.รายงาน 0.ออก")
        ch = input("เลือก: ")
        if ch == "0":
            break
        if ch in menu:
            menu[ch]()
        else:
            print("เลือกไม่ถูกต้อง")

main()

  • แยกเป็นฟังก์ชันครบทั้ง 5 ส่วน + มีเมนูหลักวน loop
  • มี validation ทุกจุดที่รับค่าจากผู้ใช้
  • ใช้เปลี่ยน status เป็น "ยกเลิก" แทนการลบทิ้ง (soft delete) แล้วเขียนอธิบายว่าเพื่อเก็บประวัติไว้ตรวจสอบ จะได้คะแนนเพิ่ม
  • ถ้ามีเวลา เขียนเพิ่มว่าถ้าใช้ฐานข้อมูลจริง ส่วนจองคิวจะเป็น INSERT และส่วนยกเลิกจะเป็น UPDATE queue SET status='ยกเลิก' WHERE no=?

รูปที่ 1 · โปรแกรมหลัก (Login → เมนูวนซ้ำ → แยกไปแต่ละส่วน)

สี่เหลี่ยมมีขีดข้าง = Predefined Process (เรียกโปรแกรมย่อย มีรายละเอียดแยกอีกรูป)

รูปที่ 2 · โปรแกรมย่อย "จองคิว" (ส่วนที่มี validation เยอะที่สุด)

เทคนิคในห้องสอบ
  • ส่วนที่เหลือ (ค้นหา / ยกเลิก / รายงาน) ถ้าเวลาไม่พอ วาดแค่รูปที่ 1 + รูปจองคิว แล้วเขียนอธิบายส่วนที่เหลือเป็นข้อความสั้นๆ
  • ทุกทางแยก (ข้าวหลามตัด) ต้องเขียน ใช่ / ไม่ใช่ กำกับทั้งสองทาง
  • ทุก loop ต้องมีลูกศรวนกลับ และต้องมีทางออก (count = 3, choice = 0)

เขียนเป็นขั้นตอนมีเลขกำกับ บอกให้ชัดว่า รับอะไร → ตรวจอะไร → ถ้าผิดทำอะไร → ถ้าถูกทำอะไร → ไปข้อไหนต่อ

  1. เริ่มต้น สร้างรายการคิวว่าง (queues) และให้หมายเลขคิวถัดไป = 1
  2. Login
    1. ให้ count = 0
    2. รับ username และ password
    3. ถ้าถูกต้อง → แสดง "เข้าสู่ระบบสำเร็จ" ไปข้อ 3
    4. ถ้าไม่ถูกต้อง → count = count + 1 · ถ้า count = 3 แสดง "ล็อกบัญชี" แล้วจบโปรแกรม · ถ้ายังไม่ครบ กลับไปข้อ 2b
  3. เมนูหลัก แสดงเมนู 1 จองคิว · 2 ค้นหา · 3 ยกเลิก · 4 รายงาน · 0 ออก แล้วรับ choice
    • 0 → จบโปรแกรม · 1–4 → ไปข้อ 4–7 · อื่นๆ → แสดง "เลือกผิด" · ทำเสร็จทุกข้อกลับมาข้อ 3
  4. จองคิว
    1. รับเลขบัตรประชาชน · ถ้าไม่ใช่ตัวเลข 13 หลัก → แจ้ง "เลขบัตรไม่ถูกต้อง" กลับเมนู
    2. แสดงบริการ 1 จดทะเบียนสิทธิ 2 รังวัด 3 ขอคัดสำเนา แล้วรับตัวเลือก · ถ้าไม่ใช่ 1–3 → แจ้ง "ไม่มีบริการนี้" กลับเมนู
    3. รับวันที่
    4. ตรวจทุกคิวในรายการ ถ้ามีคิวที่เลขบัตรและวันที่ตรงกัน และสถานะเป็น "จอง" → แจ้ง "จองซ้ำ" กลับเมนู
    5. บันทึกคิวใหม่ (หมายเลขคิว, เลขบัตร, บริการ, วันที่, สถานะ = "จอง")
    6. แสดงหมายเลขคิว แล้วเพิ่มหมายเลขคิวถัดไปขึ้น 1
  5. ค้นหาคิว รับเลขบัตร → วนดูทุกคิว แสดงคิวที่เลขบัตรตรงกัน (หมายเลข, บริการ, วันที่, สถานะ) · ถ้าไม่พบเลยแจ้ง "ไม่พบข้อมูล"
  6. ยกเลิกคิว
    1. รับหมายเลขคิว · ถ้าไม่ใช่ตัวเลข → แจ้งเตือน กลับเมนู
    2. ค้นหาคิวที่หมายเลขตรงและสถานะ "จอง" · ถ้าไม่พบ → แจ้ง "ไม่พบคิวนี้"
    3. ถามยืนยัน (y/n) · ถ้า y เปลี่ยนสถานะเป็น "ยกเลิก" (ไม่ลบทิ้ง เพื่อเก็บประวัติ) แล้วแจ้ง "ยกเลิกแล้ว"
  7. รายงาน รับวันที่ → สำหรับแต่ละบริการ นับคิวที่วันที่ตรงและสถานะ "จอง" → แสดง "ชื่อบริการ : จำนวน คิว"
จุดที่ทำให้ได้คะแนน
  • มีเลขข้อ และบอกว่า "กลับไปข้อ…" ตรงที่วนซ้ำ (แทนลูกศรวนใน flowchart)
  • ทุกจุดที่รับค่ามี "ถ้า… ให้…" (validation) ครบเหมือนในโค้ด
  • ใช้คำว่า รับ / แสดง / ถ้า / มิฉะนั้น / วนซ้ำ / จบ ให้คงที่ คนตรวจอ่านง่าย
